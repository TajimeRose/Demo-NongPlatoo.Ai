# Damo NongPlatoo.Ai

เว็บไซต์สาธิตหน้าตาและองค์ประกอบของโปรเจกต์ NongPlatoo.Ai สำหรับใช้ในการนำเสนอ
โปรเจกต์นี้ใช้ข้อมูลภายในทั้งหมดและไม่ต้องเชื่อมต่อ backend, Firebase, AI, ข่าวสด,
สภาพอากาศสด, ไมโครโฟน หรือกล้อง

## เริ่มใช้งาน

```bash
npm install
npm run dev
```

เปิด `http://localhost:8080`

## สร้างไฟล์สำหรับนำขึ้นเว็บ

```bash
npm run build
```

ไฟล์ที่ build แล้วจะอยู่ในโฟลเดอร์ `dist`

## หน้าสาธิต

- หน้าแรก
- รายการและตัวกรองสถานที่ท่องเที่ยว
- รายละเอียดสถานที่และแผนที่ preview
- แชต AI แบบ mock response
- ข่าวสารและสภาพอากาศแบบข้อมูลจำลอง
- เข้าสู่ระบบและสมัครสมาชิกแบบ demo-only
